# Yavuz Çelik

Full Stack .NET Developer — Sakarya, Türkiye

## About me

I'm a Full Stack developer focused on backend development with C# and .NET. I build and maintain web, mobile and desktop applications, and work on integrations between ERP systems, payment providers, marketplaces and internal tools.

I'm currently pursuing an M.Sc. in Data Science and Artificial Intelligence at Sakarya University. My research is on FormReader, a system for extracting structured data from handwritten Turkish production forms using OCR and computer vision. The research is supported by a Sakarya University BAP project.

I'm interested in backend architecture, document AI, OCR and applied machine learning.

## What I work on

- **Multi-tenant B2B/B2C e-commerce platforms** — a .NET 8 core product adapted for companies in different industries, automating the order-to-invoice cycle against Logo and Bay.t ERPs
- **Account reconciliation SaaS** — ASP.NET Core with Clean Architecture, using an allow-listed relay agent so ERP database credentials never leave the company
- **Field sales automation** — a React Native / Expo app with an ASP.NET Core JWT API, GPS-stamped visits and push notifications
- **ERP integration tools** — desktop toolkits and Windows services that sync documents, taxpayer records and orders between ERPs and external systems
- **FormReader** — OCR and computer vision pipelines with Python, OpenCV and PaddleOCR/SVTR, plus experiments with vision-language models for handwritten forms

Most of my work lives in private company repositories, so this profile doesn't show much of it. I'm happy to walk through the architecture and the code in an interview.
